# 0002. Arquitetura SaaS Multi-Tenant com Next.js App Router, TypeScript, Prisma e PostgreSQL

Status: accepted

Adotamos **Next.js (App Router + TypeScript)**, **Prisma ORM** e **PostgreSQL** como stack oficial do produto **Avance SaaS Multi-Tenant Financeiro e de Metas** (conforme decisão executiva autorizada em `AV-87` / `3ab7af11-1bc4-4af4-b24f-dcb4d8a4d37b`), estruturando o sistema em três camadas desacopladas com isolamento estrito por `tenantId`:

1. **Núcleo de Domínio Puro (`src/domain/`)**: Todas as regras de negócio dos 4 módulos (Módulo 1: `Controle Finanças` com regra de último saldo informado, status automático `✔`/`⏳`/`⚠`/`—` e KPIs; Módulo 2: `Cartões de Crédito` com reconciliação `Detalhado` × `Fatura informada` → `Valor Considerado` e motor de parcelamento com saldo pós-dezembro; Módulo 3: `Propósitos e Metas` plurianuais e conquistas extras de compensação; Módulo 4: `Plano de Ação das Metas` com os 4 tipos de acompanhamento `SOMA`, `LIMITE_MAXIMO`, `ULTIMO_VALOR_REDUZIR`, `MARCO_TEXTO` e vínculo estruturado com `Controle Finanças`, mais o gerador de `Tenant Template Seed` sem dados pessoais) são implementadas como funções puras e determinísticas em TypeScript, sem dependência de banco ou framework web.
2. **Persistência e Isolamento Multi-Tenant (`prisma/schema.prisma` + `src/server/`)**: O schema Prisma modela explicitamente `Tenant`, `User`, `FinancialAccount`, `FinancialCategory`, `MonthlyBudgetEntry`, `CreditCard`, `CreditCardInvoice`, `InstallmentPurchase`, `Goal`, `ExtraAchievement`, `GoalIndicator` e `IndicatorMonthEntry`. Todas as operações de repositório e serviços de aplicação exigem `tenantId` obrigatório na fronteira de entrada, impedindo vazamento entre organizações e suportando execução determinística em testes de integração e API routes.
3. **Interface Full-Stack (`src/app/`) e Preservação de `ADR-0001`**: A aplicação Next.js App Router expõe rotas de API REST/JSON (`/api/v1/...`) e o painel web interativo unificado para os 4 módulos e administração SaaS (seleção de tenant/plano, perfil `PF`/`PJ`, criação de novo tenant com template inicial zerado). Os testes de fumaça das skills em `tests/skills-smoke/` permanecem intocados e isolados conforme `ADR-0001`.
